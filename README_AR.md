# بوت Telegram للرشق — Render

## مهم قبل التشغيل
- هذا المشروع يفترض أن مزودك يدعم صيغة SMM Panel API القياسية: `services`, `balance`, `add`, `status`.
- يجب التأكد من توثيق `https://bot.tota.click/api/v2`؛ إذا كانت أسماء الحقول أو صيغة الاستجابة مختلفة فسنعدل الكود حسب التوثيق.
- مفتاح API الذي أرسلته سابقاً مكشوف. ألغِه/ولّد مفتاحاً جديداً قبل التشغيل، ولا تضعه في المحادثة أو GitHub.
- لا ترفع ملف `.env` أو أي مفاتيح إلى GitHub.

## الملفات
- `index.js`: كود البوت.
- `package.json`: المكتبات وأمر التشغيل.
- `.env.example`: أسماء المتغيرات المطلوبة.
- `render.yaml`: إعداد Render اختياري.

## النشر من الهاتف
1. أنشئ مستودع GitHub جديداً فارغاً باسم `telegram-smm-bot`.
2. ارفع ملفات هذا المجلد إلى المستودع (لا ترفع `.env`).
3. في Render اضغط New → Web Service، ثم اختر مستودع `telegram-smm-bot`.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. في Environment أضف:
   - `BOT_TOKEN` = توكن BotFather
   - `SMM_API_URL` = `https://bot.tota.click/api/v2`
   - `SMM_API_KEY` = مفتاح API الجديد
   - `ADMIN_ID` = رقم Telegram الخاص بك (أرسل `/id` للبوت بعد تشغيله)
7. اضغط Deploy.

## أوامر الإدارة
- `/id` يعرض رقم Telegram.
- `/addbalance USER_ID AMOUNT` لإضافة رصيد محلي يدوياً.
- `/panelbalance` يعرض رصيد لوحة API.

## ملاحظات
- رصيد المستخدمين هنا محلي ويُشحن يدوياً من الإدارة؛ لا توجد بوابة دفع مدمجة.
- قاعدة البيانات محفوظة في `data.json`. على استضافة مجانية ذات نظام ملفات مؤقت قد تُفقد البيانات عند إعادة النشر/إعادة التشغيل. استخدم تخزيناً دائماً أو قاعدة بيانات قبل استقبال مستخدمين حقيقيين.
- Render Free قد يوقف الخدمة عند الخمول، لذلك لا يضمن 24/7.
